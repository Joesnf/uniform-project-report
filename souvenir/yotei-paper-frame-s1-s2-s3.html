SNOW FLOW 10th ANNIVERSARY · FIXED CONCEPT DEFINITIONS

羊蹄山紙製相框｜S1 · S2 · S3

三個方案不再改成新的產品類型；差異只放在「怎麼站起來／怎麼打開／使用者做了什麼」。視覺語言可以保持一致。
這一版的修正重點：S1、S2、S3 都保留。S2 是 A-frame，不是層疊紙雕；S3 是 真正的 Pop-up card / 地方紀念卡，不是 A-frame。S1 則是最傳統、最直接的後方支架式相框。
S1 · REAR KICKSTAND FRAME

後撐架式相框

相框本身就是成品；只把後腳打開。
動作：OPEN LEG → INSERT PHOTO → DISPLAY
  • 正面是一整片羊蹄山輪廓。
  • 背面只有一支 easel / kickstand。
  • 最像一般相框，理解成本最低。
  • DIY 感最低，價值主要靠紙材與外觀。
不要畫成：整個前後兩片打開成三角形。那是 S2。
S2 · ONE-SHEET A-FRAME

A-frame 一折完成

整張紙自己成為支架；收到的人完成最後一折。
動作：FLAT → ONE FOLD → A-FRAME → PHOTO
  • 沒有獨立後腳；前片與後片本身共同支撐。
  • 側面一定要清楚看得到「△」。
  • 比 S1 多一個「我把它完成」的動作。
  • 仍然可以折回平面，方便旅客帶走。
不要畫成：多層插片、紙雕場景或 kickstand。S2 的差異就是 A-frame 本體。
S3 · LOCAL LANDMARK POP-UP

地方特色 Pop-up Card

先是一張卡；打開後羊蹄山／雪景立起來。
動作：OPEN CARD → POP-UP → DISPLAY / PHOTO
  • 產品認知先是「旅遊紀念卡」，再變成立體展示物。
  • 羊蹄山、樹林、滑雪者等可從中央折線展開。
  • 照片可以成為場景的一部分，但不是唯一主體。
  • 三案中地方紀念品感最強、紙工程也最高。
不要畫成：三角帳篷相框。那是 S2；S3 的核心是「卡片打開 → 內容彈起」。
