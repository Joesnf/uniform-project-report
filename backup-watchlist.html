Instructor Uniform Project · Market Scan · 2026.08.16
用途：這不是正式候選比較表，也沒有任何新增聯絡。此頁保留全面市場掃描結果，方便主要候選不足時快速啟動備案。主候選仍為 Patagonia / Norrøna / Peak Performance / Goldwin。

1 | Picture Organic Clothing — Reassessment

結論：不再列為「下一個順位」。

Picture 的 Pro Program、ski / snowboard 專業使用定位、3L shell 選擇與維修方向都很有吸引力；但我們先前已因設計與團隊外觀不符合需求而暫時排除。這不是小缺點，而是本案的必要條件之一：乾淨、低飽和、男女一致、避免明顯撞色。

因此，即使商業／售後條件可能很好，只要當季產品仍無法提供合適的男女一致低調配色，就不應因 Pro Program 而把它重新拉到第一備援。

Picture 的正確位置：條件式備案。只有未來季節出現符合我們視覺要求的男女 3L shell，才重新升級評估。

2 | Current Backup Priority

Backup 1

Rab

優勢：高耐用 3L snow shell、男女產品、成熟 repair / service 文化，產品與北海道長時間工作情境很匹配。

主要未知：日本公司採購、25–30 件庫存、未來 2–5 件追加路徑。

Backup 2

Salomon

優勢：日本通路與支援最現實，現有男女 3L snow shell，ski / snowboard 使用都合理。

主要未知：現有 Team Program 是否適用滑雪學校，以及產品／顏色延續性。

Backup 3

Mammut

優勢：日本售後與維修路徑成熟，男女 3L shell 供應穩定性相對容易驗證。

主要未知：沒有明顯制服／snow-school 方案，品牌形象偏 mountain technical。

Backup 4

Haglöfs

優勢：部分 3L freeride shell 的設計、顏色與 ski + snowboard 形象很貼近我們需求。

主要未知：日本長期採購、小量追加與售後路徑不如前三者清楚。

Conditional

Picture Organic Clothing

優勢：Pro Program 與專業使用者售後值得注意。

限制：已知設計／配色問題。除非未來產品線改善，否則不應排在 Rab / Salomon 前面。

Conditional

Teton Bros. / Houdini / Elevenate

各有產品或理念上的亮點，但目前供應、男女一致性、日本商業採購或長期補貨證據不足，不值得現在增加聯絡工作量。

4 | Trigger to Activate Backup Search

  • 四個主候選中有兩家以上無法提供 2026/27 首批 25–30 件。
  • 男女同色／相近色無法成立。
  • 2–5 件未來小量追加條件太差。
  • 產品／顏色延續或後繼型號策略無法支持團隊一致性。
  • 正式報價、維修／保固或 logo 加工條件使主候選失去合理性。

若需要啟動下一輪，建議順序：Rab → Salomon → Mammut → Haglöfs；Picture 僅在當季設計／顏色符合需求時重新加入。
